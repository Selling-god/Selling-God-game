RIFT DECK V53 적용 방법
=======================

기준: V52 CLASSIC BATTLE 또는 그 전체본

1) 서버/Render를 잠시 중지합니다.
2) V53 패치 ZIP을 프로젝트 최상위 폴더에 그대로 덮어씁니다.
3) 기존 assets 폴더는 삭제하거나 다시 업로드하지 마세요.
   - V53은 기존 몬스터/배경 이미지를 그대로 사용합니다.
4) GitHub에 변경 파일을 커밋/푸시합니다.
5) Render Web Service를 재배포합니다.
   Build Command: npm ci && npm run build
   Start Command: npm start
6) 배포 후 아래 주소를 확인합니다.
   /healthz
   deployId가 아래와 같아야 합니다.
   RIFT-V53-HELD-ITEMS-20260915
7) 브라우저가 이전 JS/CSS를 캐시했다면 Ctrl+Shift+R 또는 강력 새로고침을 1회 합니다.

전투 시작 테스트
----------------
- 원정 보너스 선택
- 야생 조우 화면에서 '전투 시작' 클릭
- 버튼에 '전투 준비 중…'이 잠시 표시된 뒤 전투 화면으로 이동하면 정상입니다.

장착 아이템 테스트
------------------
- 조우/이동 화면 상단의 'RUN / 장착' 클릭
- 몬스터 선택
- 기본 지급된 '붉은 회복열매' 장착
- 전투 화면에서 몬스터 이름 아래 열매 배지가 보이면 정상입니다.

중요
----
패치에 새 몬스터 이미지 파일은 포함되지 않습니다.
V52의 assets 폴더를 유지해 주세요.
