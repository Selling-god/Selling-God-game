# FUSEWILD Fusion Assets

이 폴더는 전투 중 5턴 융합 시스템의 시각 자산을 보관합니다.

- `frame-base.svg`, `grid-overlay.svg`, `sigil-*.svg`: 융합 UI/연출용 기본 자산
- `generated/`: 실제 몬스터 조합별 융합 PNG가 런타임에 생성되는 폴더

## v6.2.1 변경
이전처럼 브라우저 내부 SVG에 외부 이미지를 중첩하는 방식이 아닙니다. 서버가 원본 몬스터 PNG 두 장을 직접 읽어 픽셀 단위로 합성한 뒤 **실제 320x320 PNG 파일**을 `generated/`에 생성합니다. 따라서 전투창의 융합체는 빈 카드가 아니라 두 몬스터 특징이 합쳐진 스프라이트로 표시됩니다.

모든 조합 이미지를 미리 수만 장 포함하지 않고, 실제 조합이 처음 등장할 때 파일을 생성하고 이후 같은 조합에서는 그 파일을 재사용합니다.
