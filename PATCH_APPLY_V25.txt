RIFT DECK : ABYSS EXPEDITION v2.5
ROGUELITE DEPTH + READABILITY PATCH

[권장 적용 방법]
1. 현재 프로젝트 폴더를 먼저 백업합니다.
2. PATCH ZIP을 프로젝트 루트에 압축 해제합니다.
3. 같은 이름의 파일은 전부 덮어씁니다.
4. Render 사용 시 새 커밋/푸시 후 Web Service를 재배포합니다.
5. 로컬 실행 시 npm ci -> npm start 순서로 실행합니다.
