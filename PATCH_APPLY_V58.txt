RIFT DECK v5.8.0 패치 적용 안내
================================

이 ZIP은 전체 프로젝트가 아니라 교체/추가가 필요한 파일만 담은 패치입니다.
기준 버전: 사용자가 제공한 v5.7.0 프로젝트
패치 버전: v5.8.0

[적용 방법]
1) 기존 프로젝트 폴더를 백업합니다.
2) 이 ZIP의 내용물을 기존 프로젝트 최상위 폴더에 그대로 덮어씁니다.
   - server.js -> 프로젝트 루트
   - package.json -> 프로젝트 루트
   - public/app.js -> public/
   - public/styles.css -> public/
   - public/version.json -> public/
   - scripts/build.js -> scripts/
   - scripts/v58-classic-flow-fusion-test.js -> scripts/
3) 서버 환경에서 아래 순서로 확인합니다.
   npm run check
   npm test
4) 정상 통과하면 기존과 동일하게 Node Web Service로 배포합니다.
5) 배포 후 예전 CSS/JS가 남아 보이면 브라우저에서 강력 새로고침(Ctrl+Shift+R)을 1회 해주세요.

[중요]
- assets/, data/, Supabase 설정, 사용자 저장 데이터는 삭제/교체하지 않습니다.
- out/ 폴더는 패치에 포함하지 않았습니다. 실제 게임은 server.js를 실행하는 Node Web Service가 기준입니다.
- 융합 이미지는 수만 장의 정적 파일을 추가하는 대신, 두 몬스터의 계보를 이용해 서버가 조합 SVG를 즉시 생성합니다.
  따라서 기존 몬스터 이미지 자산을 그대로 사용하면서도 조합마다 외형이 달라집니다.

[이번 패치 핵심]
- 기본 전투를 1:1 중심 흐름으로 정리하고, 일반 야생에서만 낮은 확률로 더블 배틀 발생
- 전투 메뉴: 싸운다 / 봉인 / 파티 / 도주 / 융합
- 속도에 따른 선후공 처리, 도주 성공/실패 및 실패 시 적 행동
- 도주 성공 시 보상 없이 다음 웨이브 이동
- 전투 종료 후 상점 + 무료 보상 선택 흐름 강화
- 5웨이브 CAMP 화면 전면 재구성 및 글자 확대
- 새 기술 화면의 '건너뛰기'를 '남은 기술 모두 건너뛰기 -> 보상으로'로 수정
- 일반 경로는 약 1초 뒤 자동 조우 시작
- 고정 전투가 아닌 웨이브에서 낮은 확률로 4지선다형 Mystery Encounter 등장
- 융합 미리보기/전투 스프라이트/결과 연출에 실제 조합형 이미지 적용
- 전투 메시지, 버튼, 상태창, 보상/이벤트 글자 크기 확대

자세한 변경점은 RELEASE_NOTES_V58.md를 확인하세요.
