RIFT DECK v4.0.0 MONSTER EVOLUTION PATCH 적용법
================================================

권장 기준
- 현재 v3.4 EXPEDITION PARTY를 사용 중이면 PATCH ZIP을 그대로 덮어쓰기
- 버전이 섞여 있거나 파일 구조가 헷갈리면 FULL ZIP 사용

PATCH 적용
1. 현재 GitHub 프로젝트를 백업합니다.
2. PATCH ZIP을 압축 해제합니다.
3. 압축 안의 파일/폴더를 현재 저장소 최상위에 그대로 덮어씁니다.
4. GitHub에 Commit / Push 합니다.
5. Render Web Service의 자동 재배포가 끝날 때까지 기다립니다.

Render 설정
- Build Command: npm ci && npm run build
- Start Command: npm start
- Health Check: /healthz

정상 적용 확인
게임 주소 뒤에 /healthz를 붙였을 때 다음 값이 보여야 합니다.
- version: 4.0.0
- deployId: RIFT-V4.0.0-MONSTER-EVOLUTION-20260911

Supabase
- 기존 로그인/클라우드 저장이 정상이라면 새 SQL 실행은 필요 없습니다.
- Render Environment에 아래 값이 있어야 로그인/회원가입이 동작합니다.
  SUPABASE_URL
  SUPABASE_SECRET_KEY
  (또는 SUPABASE_SERVICE_ROLE_KEY)

중요
- Secret/Service Role 키는 GitHub 코드에 넣지 마세요.
- 로컬/Render에서 npm test가 모두 통과한 파일을 기준으로 패키징했습니다.
