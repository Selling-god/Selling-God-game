Selling God v6.6.1 - 기업전쟁 LIVE 가독성/클릭 수정 CLEAN PATCH

교체 파일
- app.js
- styles.css
- public/app.js
- public/styles.css

적용 방법
1. 기존 프로젝트를 백업합니다.
2. ZIP 안의 파일을 프로젝트의 같은 경로에 덮어씁니다.
3. Render에 재배포합니다.
4. 브라우저에서 Ctrl+F5로 강력 새로고침합니다.

주요 수정
- 기업전쟁 LIVE의 회사명/분석 버튼을 실제 클릭 가능하도록 재구성
- BOT 전쟁 카드 클릭 시 해당 회사 국가/검색/분석 화면으로 즉시 이동
- PROFILE 응답이 지연/실패해도 공용 시장 데이터로 분석 화면을 우선 표시
- 지분전: 이번 확보 %p, 누적 지분 %, 투입액, 기업가치 표시
- 방어전: 방어 전/후 지분, 감소폭, 방어비 표시
- 공개매수: 프리미엄, 확보 지분, 누적 지분, 투입액 표시
- 인재전/언론전/동맹: 협상력, 기세 변화, 협력지수, 기업가치 등 수치 표시
- 최근 기세를 소수점 둘째 자리까지 표시하고 기업가치 동시 표기
- 과도한 색/큰 배지 없이 기존 KX CORPORATE의 어두운 UI 톤 유지

Supabase SQL 추가 실행은 필요하지 않습니다.
