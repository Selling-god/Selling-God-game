Selling God v6.5.4 - 직원 연수 상태 표시 패치

수정 내용
- 연수는 장시간 진행형이 아니라 승인 즉시 완료되는 구조임을 화면에 명확히 표시
- 오늘 연수 완료 인원 / 전체 인원 진행바 추가
- 직원별 오늘 연수 완료 배지 및 다음 DAY 재교육 가능 표시
- 오늘 연수한 직원의 연수 버튼 자동 비활성화
- 연수 완료 시 우측 하단 완료 토스트 표시
- 같은 DAY 중복 연수 클릭 시 콘솔 Uncaught 오류가 발생하던 흐름 수정
- TRAIN RPC 404 확인 후에는 해당 접속 중 반복 404 호출을 피하고 로컬 연수로 자동 전환
