KX EXCHANGE - RENDER STATIC SITE FIX PATCH
==========================================

이 ZIP은 전체 프로젝트가 아닙니다.
기존 KX EXCHANGE 프로젝트 위에 아래 파일만 덮어쓰는 패치입니다.

교체 파일
- package.json
- package-lock.json
- render.yaml
- scripts/build.js

중요: 현재 Render 서비스는 Web Service가 아니라 Static Site입니다.
따라서 server.js / Start Command / Health Check는 사용하지 않습니다.

Render Dashboard > Settings 에서 정확히 다음처럼 설정하세요.

Build Command
npm run build

Publish Directory
out

Root Directory
비워두기

그 뒤 Manual Deploy > Clear build cache & deploy를 실행하세요.

정상 빌드 로그
[KX STATIC FIX] build starting
[KX STATIC FIX] READY
[KX STATIC FIX] out/index.html: true

이번 build.js는 안전장치로 out뿐 아니라 public/dist/build/site와 저장소 루트에도
KX EXCHANGE 정적 파일을 준비합니다. 하지만 Render의 정식 Publish Directory는 out으로 설정하세요.

정상 화면 버전 표식
KX-STATIC-RENDER-FIX-2026.09.03-G

주의
- 기존 public/index.html, public/app.js, public/styles.css는 삭제하지 마세요.
- 이 패치는 게임 본체 파일을 포함하지 않습니다.
