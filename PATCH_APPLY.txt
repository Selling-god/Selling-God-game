RIFT DECK v2.2 PATCH 적용 방법

1. GitHub 저장소의 현재 v2.1 파일을 백업합니다.
2. PATCH ZIP을 풀고 나온 파일/폴더를 저장소 루트에 그대로 덮어씁니다.
   data/profiles.json은 PATCH에 포함하지 않으므로 기존 로컬 프로필 파일을 덮어쓰지 않습니다.
3. Supabase SQL Editor에서 supabase/RUN_THIS_IN_SUPABASE_RIFT_V22.sql을 1회 실행합니다.
4. Render Web Service Environment에 SUPABASE_URL + SUPABASE_SECRET_KEY를 넣습니다.
   구형 service_role 키라면 SUPABASE_SERVICE_ROLE_KEY 이름을 사용해도 됩니다.
5. GitHub push -> Render 자동 재배포를 기다립니다.
6. /healthz에서 v2.2.0 / RIFT-V2.2-20260910 / auth=supabase 확인 후 게임을 엽니다.

기존 Render Web Service를 새로 만들 필요는 없습니다.
