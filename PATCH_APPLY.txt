RIFT DECK v2 PATCH 적용법

이 PATCH는 기존 v1 프로젝트 루트에 덮어쓰기 위한 것입니다.

1. 기존 프로젝트를 백업합니다.
2. PATCH ZIP을 기존 프로젝트 루트에서 풉니다.
3. 같은 이름의 파일은 모두 덮어씁니다.
4. PATCH에는 data/profiles.json이 들어 있지 않으므로 기존 프로필은 덮어쓰지 않습니다.
5. 터미널에서 npm ci
6. npm run build
7. npm test
8. npm start

Render:
Build Command = npm ci && npm run build
Start Command = npm start
Node = 22
Health Check = /healthz

변경 범위가 매우 크고 기존 v1이 초기 프로토타입이라면 PATCH보다 FULL ZIP으로 새 저장소를 만드는 것을 권장합니다.
