# 테스트 기록 · 2026-10-23

## 결과를 읽는 방법
이 기록은 실제로 수행한 테스트와 수행하지 못한 범위를 구분합니다.
테스트 통과는 상용 서비스 품질/모든 버그 부재/무료 서버 수용량을 보증하지 않습니다.

## 환경
- Linux container, Node.js 22.16.0.
- Chromium `/usr/bin/chromium`, Playwright, headless 실제 Canvas 렌더링.
- PC: 1440×900.
- 모바일 에뮬레이션: 390×844 세로, 844×390 가로, touch 입력 사용.
- 로컬 HTTP + 실제 WebSocket 연결. 공개 Render 서버가 아닙니다.
- 브라우저 페이지·게임 UI에서 발생한 JavaScript exception을 수집했습니다.

### 의존성 설치 검증의 제한
배포용 `package.json`/lockfile은 `ws` 8.18.3을 지정합니다.
이 환경에서는 외부 npm registry 설치가 차단되어 해당 버전을 내려받아
깨끗한 `npm ci` 설치까지 확인하지 못했습니다.

로컬 실행 테스트에는 이미 설치된 Playwright에 포함된 `ws` 8.17.1 구현을
임시 모듈 경로로 연결해 사용했습니다. WebSocket·압축 API 경로는 동일하지만,
이 결과를 **ws 8.18.3 자체를 직접 설치해 검증한 결과로 해석하면 안 됩니다.**
임시 어댑터나 `node_modules`는 배포 ZIP에 포함하지 않았습니다.

배포 시 실제 `npm ci`가 8.18.3을 설치합니다. GitHub CI에서 빌드/테스트를 다시 실행하도록 구성했습니다.
특정 새 버전이 보안상 최신이라고 주장하지 않으며, 운영 전에 의존성 보안 공지와 업데이트를 점검해야 합니다.

Render용 Node 설정은 테스트한 22 계열에서 현재 패치를 선택하도록 `NODE_VERSION=22`로 두었습니다.
새 patch의 배포 검증은 운영자의 실제 환경에서 다시 수행해야 합니다.

## 3. 실제 전투 화면 확인
`tests/visual_world.py`

테스트용 로컬 캐릭터로 숲, 달잠 유적, 재의 성채에 접속하여
스킬·보호막·기본 공격·보스 경고를 실행하고 스크린샷을 촬영했습니다.
`docs/screenshots`의 전투 화면은 실제 Canvas/DOM 실행 결과입니다.
후반부 확인을 위해 레벨·장비가 설정된 별도 로컬 fixture를 사용했습니다.
fixture 저장 파일이나 테스트용 관리자 API는 ZIP에 포함하지 않았습니다.

일부 장면의 headless 렌더링 측정(각 120프레임):
- 유적: 평균 약 25.0ms/프레임.
- 성채: 평균 약 19.2ms/프레임.
- 숲: 평균 약 16.5ms/프레임.

가상 환경의 짧은 측정이므로 실물 모바일의 FPS 보증치가 아닙니다.
브라우저 축소·설정의 효과 끄기/화면 배율 조절로 화면 부하를 조정할 수 있습니다.

## 4. 로컬 24개 동시 연결 smoke test
`npm run test:load`

- 연결: 24개, 3전투 지역에 분산.
- 측정 구간: 약 6초, 이동 및 기본 공격 요청.
- 24개 모두 연결 유지.
- 각 연결 36회 상태 수신(기본 6Hz).
- 인증 오류: 0.
- 모든 연결이 permessage-deflate 협상.
- 압축 전 JSON payload 합계: 약 5.72MB.
- 압축 후 소켓 수신 합계: 약 1.25MB.
- 이를 1인 1시간으로 단순 환산: 약 29.9MiB.

초기 페이지/이미지 다운로드와 TLS/TCP 오버헤드는 이 수치에 들어 있지 않습니다.
이는 **Render 무료 인스턴스 24명 장시간 안정성 시험이 아닙니다.**
Render CPU, Supabase 저장 지연, 실제 RTT, 장애, 장시간 메모리, 악의적 트래픽은 재현하지 않았습니다.
