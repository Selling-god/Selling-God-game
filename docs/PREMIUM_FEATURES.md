# v6.0 게임성 강화 방향

이번 버전은 단순한 '회사 수치 관리 화면'보다 **플레이 영상이 나오는 경영 게임** 쪽으로 방향을 잡았습니다.

### 1. 플레이어가 직접 개입
프로젝트를 누르고 기다리는 구조를 줄이기 위해 착수 시 3단계 의사결정 미니게임을 넣었습니다. 선택 결과에 따라 같은 예산으로 시작해도 실제 집행액이 달라집니다.

### 2. 매일 영상 소재가 생기는 구조
게임 DAY마다 오늘의 도전과 긴급 이사회 이벤트가 생깁니다. 같은 회사라도 DAY에 따라 목표와 다음 프로젝트 전략이 달라집니다.

### 3. 경쟁 구도 강화
내 순위만 보여주는 것이 아니라, 바로 위 경쟁사를 Rival Target으로 잡아 기업가치 차이를 보여줍니다.

### 4. 유튜브/스트리밍 친화 기능
Creator HUD를 켜면 화면에 회사명, 순위, 기업가치, 영업이익, 시즌 점수, 오늘의 도전이 고정됩니다. 현재 플레이 상태를 한 줄로 복사하는 기능도 추가했습니다.

### 5. 하이라이트 자동 기록
완벽한 프로젝트 착수, M&A, 해외진출, 언론 기사, 경영권 위기, 순위 돌파 등이 자동으로 하이라이트 릴에 남습니다.

### 6. 판매형 게임에 가까운 피드백
성공/실패/뉴스/경보에 효과음이 들어가고, 시즌 점수와 등급, 연속 성공 기록이 누적되어 플레이 목표가 생깁니다.
