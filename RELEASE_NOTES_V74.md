# FUSEWILD v7.4.0 — QA Refresh

This release is a stabilization refresh of v7.3 rather than a feature expansion.

- Reinforces mobile no-clipping behavior for battle and post-battle screens.
- Keeps readable move/status text and lets the document scroll instead of shrinking content.
- Reinforces post-battle shop/reward containment so the footer cannot cover the last row.
- Adds long-name and status overflow guards.
- Prevents combatant dimming during server resolution phases.
- Cleans cured live-status UI and stale battle-exit timers.
- Replaces the obsolete all-historical test runner with a current 24-test release gate.
- Revalidates all 1,319 PNG assets and catalog asset references.
