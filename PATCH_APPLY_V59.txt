RIFT DECK v5.9 실제 코드 패치 적용법
=====================================

기준: 이전에 제공한 v5.8 패치가 적용된 프로젝트

1) 기존 프로젝트를 먼저 백업하세요.
2) 이 ZIP의 `RIFT_V59_PATCH` 폴더를 엽니다.
3) `RIFT_V59_PATCH` 안의 파일/폴더 구조를 그대로 기존 프로젝트 루트에 덮어쓰세요.
   예:
   - RIFT_V59_PATCH/server.js               -> 기존 server.js
   - RIFT_V59_PATCH/public/app.js           -> 기존 public/app.js
   - RIFT_V59_PATCH/public/styles.css       -> 기존 public/styles.css
   - RIFT_V59_PATCH/public/index.html       -> 기존 public/index.html
   - RIFT_V59_PATCH/scripts/build.js        -> 기존 scripts/build.js
   - RIFT_V59_PATCH/scripts/v59-...test.js  -> 기존 scripts/ 아래 새 파일
4) package.json / package-lock.json도 함께 덮어쓰세요.
5) 가능하면 프로젝트 루트에서 다음을 실행하세요.

   npm run check
   npm test

6) Render/GitHub에 올리는 경우 이번 패치의 public/index.html도 반드시 올리세요.
   app.js/styles.css cache key를 v5.9로 바꿨기 때문에 예전 JS/CSS 캐시가 남는 문제를 막습니다.

중요
----
- 전체 프로젝트가 아니라 수정/추가 파일만 들어 있는 패치입니다.
- 실제 수정 코드는 server.js, public/app.js, public/styles.css 등에 들어 있습니다.
- `V59_CODE_DIFF.patch`를 열면 v5.8 대비 실제 코드 변경을 바로 확인할 수 있습니다.
