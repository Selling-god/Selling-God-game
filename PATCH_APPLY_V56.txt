RIFT DECK V56 패치 적용 방법
============================

권장 기준: V55 프로젝트

1. 프로젝트를 백업합니다.
2. V56 PATCH ZIP을 프로젝트 최상위 폴더에 풉니다.
3. 같은 이름의 파일은 덮어씁니다.
4. 기존 assets 폴더는 삭제하거나 교체하지 마세요.
   - V56 패치에는 새 몬스터 이미지가 필요하지 않습니다.
5. 터미널에서 실행:
   npm ci
   npm test
   npm start
6. 브라우저에서 /healthz 확인:
   version = 5.6.0
   deployId = RIFT-V560-FUSION-PP-BATTLE-20260916

Render / 휴대폰
---------------
Static Site가 아니라 반드시 Node Web Service로 배포해야 합니다.

Render -> New -> Web Service
Build Command: npm ci && npm run build
Start Command: npm start
Health Check Path: /healthz

또는 저장소의 render.yaml을 사용해 Blueprint/Web Service를 생성할 수 있습니다.
배포 후 휴대폰에서는 새 Web Service의 onrender.com 주소로 접속하세요.
기존 Static Site 주소를 계속 사용하면 '게임 서버 주소가 아닙니다' 진단 페이지가 나옵니다.
