Selling God v6.5.2 패치 적용 안내

이번 ZIP은 기존 프로젝트에서 교체할 파일만 들어 있는 패치입니다.

교체 파일
- /app.js
- /styles.css
- /public/app.js
- /public/styles.css

이번 수정 내용
1. 직원 연수 오류 보완
   - 종합 연수 / 전문 연수 동작
   - 서버 TRAIN RPC가 404/미구현이면 게임 내 보완 로직으로 연수 처리
   - 연수 결과와 비용/횟수 반영

2. 튜토리얼 전면 재구성
   - 주요 버튼을 실제 테두리로 강조하면서 기능 설명
   - 경영 홈 / 사업 / 직원 / 연수 / M&A / 뉴스 / 순위 안내

3. 화면 겹침 수정
   - 사업 운영 상단 탭이 아래 제목/결재 영역을 덮지 않도록 sticky 겹침 제거
   - 모바일에서도 같은 방식 적용

4. 타 회사 직원 이직 제안 보완
   - 서버 POACH RPC가 404/미구현일 때도 게임 내 보완 로직으로 제안 가능
   - 제시 월급, 사인보너스, 회사 매력도, 직원 능력에 따라 수락확률 계산
   - 성공 시 실제 내 핵심인재 목록에 추가되고 비용 반영
   - 실패 시 헤드헌터 착수비 발생

5. 지원자 능력/보상 현실화
   - 내 회사 가치 + 평균 급여 + 회사 평판을 합산해 '채용 매력도' 계산
   - 회사가 크고 급여가 높을수록 더 높은 능력/잠재력의 지원자 등장
   - 최상위 인재는 월 수천만~1억 원대 보상 요구 가능
   - 채용 후에도 표시된 능력치가 유지되도록 보완

6. 기사 대상 선택 UX 수정
   - 회사 검색에서 정확히 검색되거나 결과를 클릭하면 바로 기사 대상이 됨
   - 별도의 '대상 선택' 드롭다운을 다시 고를 필요 없음

7. 경영권 위험도 수정
   - control_case뿐 아니라 실제 외부 보유지분 전체를 합산
   - stake / percent / stake_pct / ownership_pct 등 여러 데이터 형식 대응
   - 외부지분이 위험구간이면 0%로 잘못 뜨지 않도록 수정
   - 10% 이상부터 직원 긴급보고/경영권 방어 제안 생성
   - 자사주 매입, 지분 협상, 백기사, 유상증자, 역인수 등 상황별 대응안 제시

적용 후 Render에서 재배포하면 build 스크립트가 public 파일을 root에도 동기화합니다.
브라우저에는 이전 파일이 남아 있을 수 있으므로 배포 후 강력 새로고침(Ctrl+Shift+R)을 1회 권장합니다.
