작성일: 2026-10-24

이 ZIP은 기존 게임에 덮어쓸 수정 파일과 새로 추가한 코드만 담았습니다.
기준 원본: Selling-God-game-main(2).zip
이전에 제공한 UI 정렬, 키 설정, 이동·카메라, 성장 곡선, 개인 도전 수정도 포함합니다.
이 누적 수정본을 적용한 뒤 예전 수정본을 다시 덮어쓰지 마세요.

1. 적용 방법

1) 실행 중인 게임 서버를 멈추고, 현재 프로젝트와 저장 데이터를 백업합니다.
2) ZIP 안의 client, server, shared, public, tests 폴더를 기존 package.json이
   있는 게임 루트에 복사합니다. 같은 이름의 파일은 덮어씁니다.
   폴더 전체를 지우고 교체하지 말고, 기존 폴더에 파일을 합쳐 주세요.
3) 기존 게임 루트에서 다음 명령을 실행합니다.

   npm run build
   npm start

   기존 실행 관리자나 호스팅을 사용하는 경우 npm run build 후 해당 서버를
   재시작하면 됩니다. 서버는 수정된 server 코드를, 브라우저는 새로 빌드한
   client/shared/public 코드를 함께 사용해야 합니다.
4) 브라우저에서 강력 새로고침(Ctrl+F5 또는 해당 브라우저의 캐시 새로고침)을 합니다.

추가 게임 런타임 의존성은 없습니다. 기존 package.json/package-lock.json과
public/assets, 환경변수, 계정·저장 파일은 그대로 사용합니다. 별도의 DB SQL 변경은
필요하지 않습니다. 새 게임 기록은 기존 캐릭터 상태 안에 저장됩니다.

이 ZIP만 별도 폴더에 풀어 실행하는 방식은 아닙니다. 전체 게임 이미지·음원·기존
비수정 소스는 원본 프로젝트에 있습니다. 이전에 직접 수정한 파일이 있다면,
CHANGED_FILES.json의 경로와 비교해 그 부분을 먼저 보관해 주세요.

2. 단계별 실제 지역 확장

일반 공개 지역: 92개에서 164개로 확장했습니다.
이 중 원정 소지역은 총 144개이며, 이름 있는 권역은 16개입니다.
기존 저레벨 지형·스승·포탈·직업 동선은 유지했습니다.

다음 8개 후반 권역에 각각 9개 소지역, 총 72개를 추가했습니다.

  Lv.35~49    태양흔 고원
  Lv.50~69    심해의 회랑
  Lv.70~89    잊힌 거목의 심장
  Lv.90~109   멈춘 시계의 성채
  Lv.110~134  폭풍왕의 옥좌
  Lv.135~159  공허의 국경
  Lv.160~179  별을 벼리는 용광로
  Lv.180~200  새벽의 끝

각 소지역에는 실제 이름, 지형, 포탈, 지역 레벨, 몬스터, 보급 야영지, 기록,
자원과 시련이 있습니다. 3×3 길망으로 인접 소지역끼리 연결됩니다.
각 권역의 원정길은 해당 중심 지역의 남동쪽 관문에서 시작합니다.

대륙 지도에서 '고레벨 지역 35~200' 묶음을 없애고 각 권역을 별도 탭으로
표시합니다. 전체 거점은 필요 레벨 순서로 정렬했습니다. 야영지·탐사·기록·일일
의뢰 보상은 지역에 맞추어 조정하며 첫 발견·일일 보상 중복 수령을 막았습니다.
최고 레벨 200과 완만해진 성장 곡선, 저레벨 몬스터 경험치 감쇠도 유지합니다.

3. 도트 전투 이펙트와 보스 경고

스킬을 저해상도 정수 픽셀 셀로 그린 뒤 선명하게 확대합니다. 근접 검기, 화살,
마법탄, 화염, 얼음, 낙뢰, 자연, 시간, 공허, 불사조, 파도와 회복·보호막·회피를
직업과 기술에 맞추어 구분했습니다. 추가 이미지 파일은 필요하지 않습니다.

보스 공격의 바닥 색은 지형 아래에, 위험 테두리와 중요한 안내는 지형·캐릭터·
장식 효과 위에 그립니다. 피해 숫자가 많아져도 보스 타격 효과가 밀리지 않도록
별도 큐를 사용합니다. 누락됐던 월식 안전 사분면의 발동 효과도 연결했습니다.
설정에서 선택 이펙트를 꺼도 공격 범위, 안전 구역과 실제 보스 발동은 보입니다.

4. 파티 던전 3종

메뉴: 탐험 수첩 → 파티 던전 / 파티 → 파티 던전 / 대륙 지도 → 파티 던전
필드 입구 가까이에서 상호작용 키(기본 F) 또는 클릭으로도 열 수 있습니다.

입장: 같은 서버의 2~4명이 기존 파티를 만들고, 해당 입구로 모입니다.
파티장이 준비 확인을 요청하고 각자 준비 완료를 누르면 파티장이 입장합니다.
입장 직전에 레벨·거리·생존·전투 종료·파티 구성을 다시 검사합니다.

[쌍월의 용광로] Lv.35 · 태양흔 고원의 출발 지점 근처
  해·달 역할에 맞는 발판을 전원이 2초 동안 유지한 뒤, 해당 역할의 사람이
  각 기둥을 목표 방향으로 돌립니다. 후반에는 역할과 발판 구성이 바뀝니다.

[뒤집힌 기억의 서고] Lv.80 · 잊힌 거목의 심장 출발 지점 근처
  문양 순서 3/4/5개를 기억하고 지정된 사람이 교대로 장치를 작동합니다.
  다음에는 유도자가 프리즘 뒤에 서고 나머지 파티원이 기록 고정진을 유지해
  광선을 차단합니다. 기억할 순서는 미리보기 후 사라집니다.

[낙성의 심연] Lv.140 · 공허의 국경 출발 지점 근처
  표식 대상은 바깥 봉인으로 유성을 유도하고, 다른 사람들은 중앙에 모입니다.
  이후 지정된 두 사람이 차단기를 2초 안에 작동하고 1.2초간 유지합니다.
  후반에는 연결된 두 사람이 서로 떨어져야 하는 분리 사슬이 추가됩니다.

세 보스 모두 체력 70%와 35%에서 다음 협동 기믹을 반드시 거칩니다.
큰 한 방이나 지속 피해로 단계가 생략되지 않습니다. 모든 패턴은 2인으로도
해결할 수 있고, 파티 인원에 맞추어 보스 체력을 조정합니다.

기믹 실패 3회 또는 전원 사망 시 실패 이유가 남습니다. 전원이 재도전 준비를
누르면 같은 인스턴스에서 새 시도를 시작합니다. 한 시도에 동료 구조 2회가
가능하며, 쓰러진 사람 가까이에서 상호작용한 뒤 3초 동안 머물러야 합니다.

접속이 끊기면 30초 동안 전투·기믹 시간을 정지합니다. 제시간에 돌아오면
이어지고, 유예 만료·파티 이탈·중도 퇴장 시 파티가 안전하게 복귀합니다.
일반 사망 손실은 없고, 사용한 물약은 소비됩니다. 최종 퇴장 시 입장 전 HP/MP로
돌아갑니다. 서버 재시작으로 진행 중인 인스턴스가 사라져도 입장 위치로 복구됩니다.

던전별 첫 완료 성물, 개인 최고 기록, 계약의 증표, 증표 교환을 제공합니다.
첫 클리어한 날에 반복하면 추가 보상 없이 기록만 갱신합니다. 다음날부터
하루 첫 재완주는 증표·골드를 줍니다. 파티별 적·공격·힐·효과·보상은 분리됩니다.

5. 특별한 방법으로 들어가는 숨은 세계

일반 지역 164개와 별도로 3개 세계 × 정원/성소 2개 = 숨은 지도 6곳을 추가했습니다.
메뉴는 탐험 수첩 → 경계의 수첩입니다. 입구 흔적이나 관련 기록을 발견하면
그 세계의 이름과 단서가 수첩에 나타납니다. 일반 지도에는 처음부터 공개하지 않습니다.

[백광의 천상] Lv.60
  입구: 심해의 회랑 → 난파 함대의 묘지, 야영지 동북쪽
  단서 두 기록 + 세 종의 순서를 이용합니다.
  정원: 구름 위의 잃어버린 정원 / 성소: 천상의 마지막 성소
  파수꾼: 날개를 거둔 심판자 · 세라온
  전직 흔적: 별을 엮는 자, 심해의 예언자

[재 아래의 지옥] Lv.110
  입구: 멈춘 시계의 성채 → 두 번째 새벽의 종루, 야영지 동북쪽
  단서 두 기록 + 풀어야 할 봉인의 선택과 순서를 이용합니다.
  정원: 끊어진 사슬의 낙원 / 성소: 저주가 잠든 용광로
  파수꾼: 사슬의 주인 · 바르칸
  전직 흔적: 불사조의 계승자, 이름 없는 왕

[뒤집힌 성좌] Lv.160
  입구: 공허의 국경 → 문을 삼킨 자의 앞뜰, 야영지 동북쪽
  단서 두 기록 + 좌우가 반전되는 좌표 발판을 이용합니다.
  정원: 나를 먼저 기억한 거울길 / 성소: 반전된 왕좌의 안쪽
  파수꾼: 이름을 비추지 않는 왕 · 에이돈
  전직 흔적: 공허를 걷는 자, 월식의 집행자

최초 개방은 캐릭터별로 저장합니다. 이후 별여울 마을 또는 원래 경계문에서
정원으로 재입장할 수 있습니다. 다른 사람이 의식을 풀어도 내 진행은 바뀌지 않습니다.
정원 안의 개인 서약을 마쳐야 안쪽 성소에 들어가고 파수꾼에게 피해를 줄 수 있습니다.
서약을 마친 탐험가들은 성소에서 함께 싸울 수 있습니다.

첫 파수꾼 완주는 서약핵, 현지 재료, EXP, 골드와 칭호를 줍니다. 세계마다 지정된
기존 히든 직업 2개의 '다음 비밀 단서'도 실제로 한 단계씩 진행시킵니다.
직업 자체는 기존 스승의 전직 이야기를 끝내야 얻습니다. 이미 보상을 받은
세계에서는 EXP·서약핵·전직 단서를 반복 지급하지 않습니다.

정확한 입장 순서와 정원 시련의 해답이 필요하면 함께 넣은
HIDDEN_REALMS_SPOILERS_KO.txt를 확인하세요. 게임 안에서는 단서로 추론할 수 있습니다.

6. 신성 / 저주 / 반전 무기

각 세계 첫 완주로 얻은 서약핵을 성소 북쪽 제단에 가져가면 현재 직업 계열의
검·활·지팡이 중 한 자루를 받습니다. 세계별 1회, 총 9개 무기 정의와 각각의
안정화 형태 9개를 추가했습니다. 수령 전에 원하는 직업 계열인지 확인하세요.

천상의 서약: 체력 +180 / 마나 -60. 안정화하면 두 증감이 사라집니다.
지옥의 맹약: 같은 레벨 원정 무기보다 공격력 약 10% 증가 / 체력 -360.
               정화하면 추가 공격력과 체력 감소가 함께 사라집니다.
반전 성좌: 치명타 +14% / 방어력 -22.
             제어하면 치명타 +8%, 방어력 감소 없이 사용할 수 있습니다.

해당 성소에서 현지 재료 3개 + 레벨×5 G를 지불해 변환/역변환합니다.
강화 단계, 강화 실패 보정, 장착 상태는 유지합니다. 변환으로 무기가 복제되거나
경험치가 지급되지 않습니다. 가방에서도 음수 능력치가 올바르게 표시됩니다.

7. 앞선 요청 반영 유지

- 직업·보스·탐험 등의 데스크톱 메뉴와 스킬 바의 아래쪽 기준선을 맞췄습니다.
- 설정 → 키 설정에서 이동, 전투, 메뉴, 상호작용 등 26개 동작의 주/보조 키를
  바꿀 수 있습니다. 충돌 검사, 즉시 반영, 브라우저 저장, 기본값 복원을 지원합니다.
- 월드 보스 즉시 이동 시 안전한 위치를 찾고 서버/클라이언트 이동 상태를 초기화합니다.
- 맵 가장자리에서 카메라가 완만하게 따라가도록 조정하고 가장자리 배경을 보완했습니다.
- 최고 레벨 200, 레벨에 맞는 적과 장비, 완만해진 성장 및 낮은 레벨 사냥 감쇠.
- 개인 도전 5종: 30층 탑 / 기억의 룬 / 생존전 / 보스 연전 / 수정 수호전.
- 월드 보스 4종의 체력 단계별 기믹과 개인 도전 기록·첫 보상·증표 교환.

8. 파일과 검증

CHANGED_FILES.json: 원본 대비 바뀐 파일, 새 파일, 크기, SHA-256.
VALIDATION_REPORT.json: 실제 실행한 자동 검증과 범위·한계.
tests/*.test.js: 동봉한 회귀 테스트. 기존 프로젝트에서 npm test로 실행할 수 있습니다.

실제 Game 로직, 두 개 UI 문서, 실제 WebSocket 통신, 저장·복구, 네이티브 Canvas
렌더링을 확인했습니다. 최소 입장 레벨의 기사+술사 두 캐릭터가 실제 이동/공격/장치
입력을 사용해 세 던전을 완주했습니다. 이 자동 플레이는 기믹 실행 가능성을 검증하며,
사람이 처음 공략할 때의 체감 난이도·긴 세션의 밸런스·실제 기기 FPS를 보장하지 않습니다.
브라우저 화면을 직접 조작하는 최종 다인 플레이 테스트는 별도로 실시하지 않았습니다.
