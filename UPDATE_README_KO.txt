이번 ZIP에는 기존 프로젝트에 합칠 수정 파일과 새 코드, 회귀 테스트만 들어 있습니다.
기준 원본은 Selling-God-game-main(2).zip입니다.
이전에 제공한 키 설정, UI 정렬, 텔레포트·카메라, 성장 속도, 지역 확장,
다섯 개인 도전, 파티 던전, 숨은 세계 수정도 포함한 누적 패치입니다.
이번 수정본 적용 후 예전 패치를 다시 덮어쓰지 마세요.

1. 적용 방법

1) 게임 서버를 종료하고 현재 프로젝트와 저장 데이터를 백업합니다.
2) ZIP 안의 client / server / shared / public / tests 폴더를 기존 게임의
   package.json이 있는 루트에 합칩니다. 같은 경로의 파일은 덮어씁니다.
   기존 폴더를 삭제하고 교체하지 말고, 기존 폴더에 파일을 합쳐 주세요.
3) 게임 루트에서 실행합니다.

   npm run build
   npm start

   이미 실행 관리자나 호스팅을 사용하는 경우 build 후 기존 방식으로 재시작합니다.
4) 브라우저에서 Ctrl+F5 등 캐시를 무시하는 새로고침을 합니다.

서버와 클라이언트를 함께 갱신해야 새 공격 상태·탄환·페이즈 연출이 일치합니다.
public/assets, package.json, package-lock.json, 환경변수, 계정과 저장 데이터는
기존 것을 사용합니다. 새 게임 런타임 의존성과 DB SQL 변경은 없습니다.
이 ZIP만 빈 폴더에 풀어서 실행할 수는 없습니다. 원본의 이미지와 음원,
수정하지 않은 파일들이 필요합니다. CHANGED_FILES.json에서 포함 경로를 볼 수 있습니다.
직접 편집한 소스가 있다면 해당 파일의 변경 내용을 먼저 비교해 주세요.

2. 실제 통행 구조가 달라진 지역

공개 필드 163개와 숨은 지도 6개에 새 지형을 적용했습니다. 안전 마을 1개를
포함한 일반 지역 수는 기존 확장본과 같은 164개입니다. 이번 수정은 그 지역들의
실제 모양과 통행 방식을 바꿉니다.

22개 지역 계열에 협곡, 능선, 수로, 목책, 계단 고개, 공중 고리, 단층,
거목 미로, 작업실, 제련대, 별가지 길 등을 작성했습니다. 원정 소지역은
방향과 연결 방식이 달라지고, 숨은 정원과 성소도 서로 다른 구조입니다.

벽과 절벽은 실제 이동 및 사격을 막습니다. 물·용암·공허는 이동을 막으며,
다리와 계단을 통해 건널 수 있습니다. 투사체는 빈 공간 위를 지나갈 수 있지만
벽에는 막힙니다. 높이는 도트 절벽 면·단상·계단으로 표현합니다.
점프로 층을 넘거나 다리 위·아래를 동시에 통행하는 3D 물리는 구현하지 않았습니다.

포탈, 스승, 기록, 비밀 장치, 보스와 시련의 필수 좌표는 유지했습니다.
자원과 보물상자는 기존 ID를 유지하면서 실제 통행 가능한 곳으로 옮겼습니다.
구 저장 위치가 새 장애물 안에 있으면 로그인 시 안전한 위치로 보정됩니다.

3. 지역 몬스터와 공격 모션

16개 주요 권역에 3종씩 총 48개 지역 몬스터 정체성을 부여했습니다.
원정 소지역도 해당 권역의 몬스터군을 사용합니다. 기존 기록과 퀘스트 목표가
이어지도록 ID, 레벨, 보상과 재료는 보존하고 이름·외형·행동을 연결했습니다.

도약토끼 / 씨앗지기 / 늑대, 게 / 가오리 / 장어, 전갈 / 독수리 / 모래벌레,
버섯 / 개구리 / 두꺼비, 여우 / 부엉이 / 설인, 하피 / 그리핀 / 해파리,
외눈 / 빈 갑주 / 사냥개, 장창인형 / 드론 / 거미공작 등 지역별 생태가 다릅니다.
후반부에는 산호, 해룡, 요새거북, 사마귀, 맨드레이크, 나무거인, 가고일,
키메라, 백족충, 화로종, 모루, 기린, 연꽃정령, 여섯날개 성문지기가 등장합니다.

일반 행동은 다음 9개입니다.
  추격 근접 / 방향 고정 돌진 / 거리 유지 사격 / 도약 / 잠복 /
  부채 사격 / 지속 독 지대 / 소환 / 정면 후려치기

서버의 준비·공격·회복 시각에 맞춰 몸체와 팔다리, 날개, 집게, 무기를 움직입니다.
도약의 웅크리기, 돌진 자세, 사격 조준·반동, 잠복·출현, 소환 자세와
망치를 올렸다 내리는 동작이 서로 다릅니다. 타격이 끝나면 반격 가능한 빈틈을 표시합니다.
큰 몬스터는 도트 몸통을 눌러도 선택할 수 있습니다.

날아가는 탄환과 남아 있는 위험 지대가 실제 피해 판정과 연결됩니다.
기둥 뒤 엄폐, 방향이 정해진 공격의 옆으로 회피, 벽에 막힌 돌진 뒤 반격이 가능합니다.
소환체는 수와 수명이 제한되며 경험치·골드·처치 수를 추가로 주지 않습니다.
처치한 몬스터의 행동과 대응법은 탐험 수첩의 몬스터 도감에서 확인할 수 있습니다.

4. 서로 다른 세 파티 던전

쌍월의 용광로 / Lv.35 / 태양흔 고원
  용암 수로, 세 제련대, 연결 다리, 실제 엄폐 제련기.
  아르케: 착지 강타, 추격 화염과 지속 잔열, 연속 망치, 엄폐 가능한 열풍.
  기존 태양·달 발판과 기둥 방향 협동을 유지합니다.

뒤집힌 기억의 서고 / Lv.80 / 잊힌 거목의 심장
  네 기록실, 꺾인 통로, 중앙 광선실, 시야를 막는 서가.
  네메: 고정 광선, 순서대로 남긴 기록, 과거 위치를 되감는 시간차 공격.
  기존 기억 입력 교대와 프리즘·고정점 협동을 유지합니다.

낙성의 심연 / Lv.140 / 공허의 국경
  중앙 섬, 외곽 네 섬, 좁은 가교, 우회 연결교.
  아스트라: 중력 흡입, 외곽 유성, 다리를 따라 움직이며 남기는 붕괴 흔적.
  기존 표식 유도·보호구역, 두 도관 동시 조작과 최종 연결선 대응을 유지합니다.

셋은 실제로 다른 zone과 충돌 지도를 사용합니다.
파티 2~4명, 준비 동의, 파티장 입장, 부활, 전멸 후 재시도,
접속 끊김 유예와 기존 보상·첫 완주 기록도 유지합니다.

5. 1 → 2 → 3페이즈와 변신 컷

던전과 월드 레이드 보스는 HP 70%·35%에서 변신합니다.
던전 컷은 2.2초, 필드·월드·비밀 보스 컷은 1.8초입니다.
새 외형과 페이즈 이름, 다음 행동 설명을 도트 컷으로 표시합니다.

전환 중에는 진행 중 공격과 위험 지대·소환체를 정리하고 피해 보호를 적용합니다.
한 번의 강한 공격으로 필수 페이즈를 통째로 넘기지 않도록 체력 문턱을 둡니다.
전환 후에는 준비 표시를 거쳐 다시 공격합니다. 기존 월드 보스 목표 기믹은
변신 컷 뒤에 시작하며, 이후 페이즈에서는 새 행동과 공격 조합이 추가됩니다.
필드·월드·비밀 보스 26개 프로필과 던전 3개 프로필을 각각 작성했습니다.

변신은 입력을 받는 별도 팝업이 아닙니다. 컷이 끝나면 게임 화면으로 이어집니다.
이펙트를 꺼도 변신 안내, 공격 예고, 탄환과 잔류 위험 표시는 유지됩니다.

6. 이전 기능과 저장 호환

하단 메뉴 정렬, 26개 행동 키 변경·중복 감지·설정 저장,
월드 보스 즉시 이동 후 이동 불가 수정, 맵 가장자리 카메라 보정,
최대 Lv.200과 조정된 성장 곡선, 144개 원정 소지역, 도트 스킬 이펙트,
탑·룬·생존·보스 연전·방어전 다섯 개인 도전, 숨은 세계 여섯 지도,
히든 직업 단서와 신성·저주·반전 무기 체계를 함께 포함합니다.

정답이 필요한 경우 HIDDEN_REALMS_SPOILERS_KO.txt를 참고하세요.
처음 발견하는 재미를 원하면 해당 파일을 열지 않고 게임 속 기록부터 읽어 주세요.

7. 확인한 범위

최종 도메인·회귀 테스트 227개 통과, 실제 WebSocket·REST·저장 테스트 9개 통과,
실제 client/main.js를 실행하는 DOM 통합 확인 46개 통과.
169개 필드·숨은 지도의 연결성·필수 좌표·스폰, 3개 던전의 기믹 접근 경로 검증.
최소 입장 레벨의 2인 자동 입력으로 3개 던전의 3페이즈 완주 확인.
48종 도트, 준비·공격·회복 모션, 세 던전과 월드 보스의 단계별 외형,
탄환·지속 위험 표시, 실제 렌더러 장면 7개를 native Canvas로 확인했습니다.
원본 프로젝트에 이 ZIP의 수정 파일을 합친 상태의 빌드·시작·모듈 연결을 검사합니다.

이 확인은 자동 입력과 DOM/native Canvas 검증입니다. 실제 브라우저·모바일 기기에서
장시간 파티 플레이나 프레임 성능·사람의 체감 난이도까지 검증했다는 뜻은 아닙니다.
자동 입력 완주 시간은 사람의 예상 클리어 시간이 아닙니다.
검증 상세와 제한은 VALIDATION_REPORT.json에 담았습니다.
