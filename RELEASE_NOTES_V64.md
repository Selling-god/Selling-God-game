# FUSEWILD v6.4.0

## Post-battle UI rebuild
- Rebuilt the battle-clear shop/reward screen around the battlefield instead of stacking large panels.
- Shop items and free rewards are compact icon rows.
- Long descriptions live only in one bottom dialogue box.
- Hover/focus updates the bottom description without reflowing the layout.
- Current lead monster HP/EXP and six-party mini strip remain visible.
- Mobile uses horizontal item rows and a fixed safe-area footer instead of tall card stacks.
- Added defensive min-width/ellipsis rules to prevent long monster/move names from overlapping.

The design follows the information hierarchy of a battle-first roguelite reward screen while using original FUSEWILD art, code, and UI assets.
