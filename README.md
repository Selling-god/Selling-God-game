# RIFT DECK v4.0.0 — MONSTER EVOLUTION

RIFT DECK는 Node 동적 서버 기반의 1~4인 협동 픽셀 몬스터 로그라이트입니다.
이번 v4.0은 기존의 `유닛 카드 소환 중심` 구조를 크게 정리하고, **직접 포획한 몬스터를 원정 파티로 편성한 뒤 스펠 카드로 지휘·강화·진화시키는 전투**를 중심으로 재설계했습니다.

## 핵심 루프

`일반 여행 → 야생 몬스터 조우/포획 → 영구 몬스터 보관함 → 포인트 예산으로 원정 파티 구성 → 스펠 덱 편성 → 던전/여행 전투 → 진화·융합·공명·균열개화 → 성장한 파티로 더 깊은 층 공략`

여행에서 포획한 몬스터는 계정에 영구 저장되며, 이후 여행과 50층 던전의 시작 파티로 편성할 수 있습니다. 강한 몬스터일수록 편성 포인트가 높아 한정된 10P 안에서 조합을 고민해야 합니다.

## 전투 조작 개념

전투 카드는 몬스터 자체가 아니라 **현재 선택한 몬스터에게 내리는 스펠/명령**입니다. 공격 주문, 방어 주문, 회복, 몬스터 ATK 강화, 방어막, GENE/RES/RIFT 충전, 즉시공격 등을 조합합니다.

같은 몬스터를 연속으로 지휘하면서 주문 성격을 섞으면 COMMAND LINK가 쌓이고, 고단계에서 추가 방어·드로우·RIFT DRIVE가 발동합니다.

- version: `4.0.0`

## Supabase

기존 v3 계열 로그인/클라우드 저장이 정상이라면 **v4.0용 추가 SQL은 필요하지 않습니다.**
Render Web Service에는 다음 환경변수가 필요합니다.

- `SUPABASE_URL`
- `SUPABASE_SECRET_KEY`
  - 또는 레거시 `SUPABASE_SERVICE_ROLE_KEY`

Secret/Service Role 키는 GitHub에 커밋하지 마세요.
