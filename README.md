# FUSEWILD V8 · EXPEDITION

몬스터를 수집하고 파티를 편성해 웨이브를 돌파하는 웹 로그라이트입니다. 기존 **5턴 융합**에 **속성 연계**와 실제 적 기술에 연결된 **다음 행동 예고**를 더했습니다.

## 시작

Node 지원 범위: `>=20 <27`. 이 저장소는 정적 HTML이 아니라 **Node 서버가 필요한 게임**입니다.

```sh
npm run check
npm test
npm start
```

기본 주소: `http://localhost:3000`  
상태 확인: `/healthz`  
버전: `8.0.0` / `FUSEWILD-V800-EXPEDITION-20260921`

`out/`는 정적 호스팅 오배포 진단용입니다. 게임 실행 파일로 배포하지 마세요.

## 게임 흐름

파티 편성 → 원정 → 기술·교대·융합·봉인 → 전투 후 무료 보상 및 장착 → 선택적 상점 정비 → 직접 다음 웨이브 진행.

파티는 최대 6마리·10포인트이며 몬스터마다 기술 4개와 PP를 사용합니다. 서로 다른 속성의 공격을 3번 명중시키면 세 번째 기술의 위력 계수가 20%, BREAK가 8 증가합니다. 교대와 융합 중에도 연계가 유지됩니다.

적의 다음 기술은 서버가 미리 정하고 표시합니다. 상태이상·BREAK·행동 봉쇄에 의해 취소될 수 있으며, 보스 단계 전환 때는 계획이 다시 정해집니다.

## 모드

| 구분 | 여행 | 심연 던전 |
|---|---|---|
| 성격 | 수집·여행 | 50층 자원 관리 |
| 10웨이브 관리자 승리 | HP·PP·상태 완전 회복 | 무료 자동 회복 없음 |
| 회복 | 아이템·야영·관리자 승리 | 상점 정비·회복 아이템 |

카탈로그: 몬스터 205종, 아이템 144종. 레거시 스펠 데이터 315개도 원본에 남아 있지만 현재 전투는 몬스터 기술 중심입니다. V8이 이 콘텐츠를 새로 추가한 것은 아닙니다.

## V8 화면과 접근성

홈, 파티 편성, 전투, 보상 화면을 새로 구성했습니다. 파티 검색과 속성 구성, PP·상성·BREAK 표시, 화면 크기에 맞춘 세로 배치, 전투 속도·큰 글씨·움직임 줄이기, 키보드와 모달 포커스 처리를 제공합니다. 기존 그림과 연출은 유지합니다.

## 주요 파일

- `server.js`: API·전투·저장.
- `public/app.js`: 화면과 입력.
- `public/expedition.css`: V8 화면 배치 및 테마.
- `public/styles.css`: 기존 연출·기타 화면.
- `public/resonance.js`: 서버/브라우저 공용 속성 연계 규칙.
- `data/catalog.json`, `data/move-library.js`: 기존 게임 데이터.
- `PATCH_APPLY_V800_EXPEDITION_KO.md`: 적용·배포·백업 안내.
- `QA_REPORT_V800_EXPEDITION.md`: 26개 회귀 검사 및 화면 QA의 결과와 한계.

Supabase 설정이 있으면 기존 인증·클라우드 연동을 사용하고, 없으면 로컬 JSON 저장을 사용합니다. 이번 패치에는 데이터베이스나 계정 설정 변경이 없습니다. 기존 구조 설명은 `docs/ARCHITECTURE.md`에 있습니다. 과거 문서의 버전·화면 설명은 현재와 다를 수 있습니다.
