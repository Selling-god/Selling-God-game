# FUSEWILD v6.3.0 — MONSTER FUSION ROGUELITE

FUSEWILD는 포획한 몬스터를 편성하고, 몬스터 고유 기술로 웨이브를 돌파하고,
5턴 한정 융합으로 전황을 뒤집는 오리지널 픽셀 로그라이트입니다.

## 핵심 루프

```
야생 조우 → 상점 정비 → 무료 보상 1개 → 다음 웨이브
  5웨이브 균열 워든 · 7웨이브 균열 추적자 · 10웨이브 관리자 결투
  → 바이옴 선택 → 진화 · 융합 · 공명진화 · 균열개화
```

## 두 가지 모드

|                | 여행 (journey) | 심연 던전 (dungeon) |
|----------------|----------------|---------------------|
| 10웨이브 회복  | HP/PP/상태 완전 회복 | **없음** |
| 회복 수단      | 회복 아이템 · 야영 · 관리자 격파 | **상점 정비와 회복 아이템뿐** |
| 성격           | 학습·수집 중심 | 자원 관리 생존전 |

던전은 50층 내내 HP·PP·상태이상이 그대로 누적됩니다. 매 웨이브 상점에서
회복에 골드를 쓸지, 아이템에 쓸지 고르는 게 이 모드의 핵심 긴장감입니다.

## 전투

- 파티 최대 6마리 / 10P 예산, 기술 슬롯 4개, PP·상태이상 지속
- 루트 커맨드: **기술 · 융합 · 교대 · 봉인**
- 융합: 행동 1회를 소모해 두 몬스터를 5턴간 결합 (이 게임의 시그니처)
- 속성 상성, BREAK, 방어막, 진화 4계통
- 몬스터 205종 / 아이템 128종 / 스펠 카드 315종 / 50층

## 10웨이브 관리자 결투

각 바이옴 끝에는 이름과 대사를 가진 NPC 관리자가 2체 편성으로 승부를 걸어옵니다.
에이스는 해당 바이옴의 보스, 파트너는 그 바이옴의 상위 야생 몬스터입니다.

| 바이옴 | 관리자 |
|---|---|
| 청록 유적 | 수관지기 리엔 |
| 잿불 제련소 | 제련장 카르마 |
| 유리 설원 | 설원감시자 하베크 |
| 별의 회랑 | 성도사 벨라 |
| 기원의 문 | 문지기 오르드 |

## 개발

```bash
npm start     # 서버 실행 (기본 3000번 포트)
npm run build # 에셋·카탈로그 검증 후 version.json 생성
npm test      # 빌드 + 전체 테스트 (현재 23/23 통과)
npm run check # 문법 검사만
```

- Health: `/healthz`
- 런타임 소스: `server.js`, `public/app.js`, `public/styles.css`, `public/index.html`
- 게임 데이터: `data/catalog.json`, `data/move-library.js`
- 문서: `docs/` · 과거 릴리스 노트는 `docs/archive/`
- 은퇴한 테스트와 그 이유: `scripts/legacy/README.md`

Supabase는 설정되어 있으면 사용하고, 없으면 로컬 JSON으로 동작합니다
(`SUPABASE_URL`, `SUPABASE_SECRET_KEY`). 자세한 구조는 `docs/ARCHITECTURE.md`.

변경 내역: `CHANGELOG.md`
