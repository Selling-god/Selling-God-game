RIFT DECK V50 ORIGINAL PIXEL MONSTERS 적용 방법
================================================

1. 기존 Selling-God-game-main 폴더를 먼저 백업합니다.
2. V50 패치 ZIP을 풉니다.
3. ZIP 내부 파일/폴더를 기존 프로젝트 최상위 폴더에 그대로 덮어씁니다.
4. 터미널에서 프로젝트 폴더로 이동합니다.
5. 아래 명령으로 확인합니다.

   npm run check
   npm test

6. 실행:

   npm start

주의
----
- data/catalog.json, public/app.js, public/styles.css와 몬스터 이미지 자산이 함께 바뀌므로 일부만 선택해서 덮어쓰지 마세요.
- 기존 Supabase 설정 파일은 삭제하지 않습니다.
- 세이브에서 몬스터 ID(e001 등)는 그대로 유지하므로 기존 보유 몬스터 참조 구조는 유지됩니다.
- 이름/속성/archetype은 새 V50 외형에 맞게 변경됩니다.

- 보스: 5종 오리지널 도트 이미지
