Selling God v6.5.6 - 경영권 방어 현금 흐름 수정

핵심 수정
1. 경영권 방어 행동은 이제 전부 법인현금을 사용합니다.
   - 자사주 매입: 현금 감소
   - 공격자 지분 되사기/협상: 현금 감소
   - 백기사 확보: 현금 감소
   - 포이즌필: 현금 감소
   - 긴급 유상증자 방어: 게임 규칙상 발행/주관/할인 비용을 방어비로 처리하여 현금 감소
   - 역인수/맞지분 매입: 현금 감소

2. 현금이 증가해도 프론트에서 자동 보정
   - Supabase의 기존 방어 RPC가 잘못된 현금 증가값을 돌려주는 경우에도
     승인한 방어예산만큼은 반드시 법인현금에서 차감되도록 보정합니다.
   - 서버가 정상적으로 차감하는 경우에는 이중 차감하지 않습니다.

3. UI 보강
   - 방어 버튼에 예상 현금 지출액 표시
   - 실행 확인창에 방어비와 실행 후 예상 잔액 표시
   - AI 자동집행 결과에도 총 지출액 표시

4. 예외
   - 경쟁사/주식 보유분 '매각'은 자산을 파는 행동이므로 기존처럼 현금이 증가합니다.
   - 대출은 차입이므로 현금이 증가합니다.
