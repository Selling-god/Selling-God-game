별여울 온라인 — 외형 정상화 · 가격 재조정 · 채팅/UI 긴급 수정
기준: 직전 starfall_trials_atelier_purchase_fix_update.zip을 적용한 게임
이 패치는 전체 게임이 아니며, 변경된 코드 11개와 안내 자료만 포함합니다.

[수정 내용]
1) 코스튬: 원본 캐릭터의 얼굴, 무기, 보행 프레임이 유지되도록 옷을
   실제 캐릭터 크기의 몸통/소매/망토 레이어로 다시 제작했습니다.
   커스텀 도트 캐릭터 이미지 적용 시 원래 게임 캐릭터를 중복 출력하지 않습니다.
   날개도 어깨 뒤에서 시작하도록 크기와 기준 좌표를 줄였습니다.
2) 이름표: 캐릭터 얼굴/헤어와 겹치지 않는 15px 폭의 프레임으로 줄이고
   닉네임, 칭호, 타 플레이어 레벨 표시의 수직 위치를 분리했습니다.
3) 가격: 꾸미기 아이템의 유료 가격을 기존 대비 5~10배 수준으로 인상했습니다.
   5개 부위 무료 입문 아이템은 0G 유지, 이미 산 아이템과 장착 상태는 유지.
   닉네임 변경권: 2,200G -> 17,600G (8배)
   초상화 변환권: 1,500G -> 10,500G (7배)
   핵심 플레이용 일반 물약/재료 가격은 변경하지 않았습니다.
4) 채팅: 보스 '출현·격파' 전역 채팅 알림은 월드 보스만 표시합니다.
   지역 보스 격파 전역 문구를 제거하고 월드 보스 일정만 구분 전송합니다.
   지역 제단/일반 기믹 안내는 채팅에 쌓지 않고 HUD/간단 알림으로 확인합니다.
   이용자 일반·파티 채팅은 기존대로 작동합니다.
5) 채팅·스킬바 겹침: PC 폭 701~1599px에서 스킬바 위쪽에 별도 채팅 위치,
   휴대폰 세로/가로 화면 별 대응. 기존 메뉴·스킬바 아래쪽 정렬 유지.

[적용 방법]
1. 실행 중인 게임 서버를 종료하고 게임 폴더와 저장 데이터를 백업하세요.
2. 이 ZIP의 client/, server/, shared/, public/ 폴더를 게임 프로젝트 안의
   동일한 폴더 위치로 합쳐서 동명 파일을 덮어쓰세요.
   주의: 기존 폴더를 통째로 삭제하면 안 됩니다.
   tests/ 폴더는 테스트용이며 일반 플레이에는 필수가 아닙니다.
3. 터미널에서 package.json이 있는 경로로 이동한 후:
   npm run build
   npm start
   (기존 PM2/Render 등으로 운영했다면 사용 중인 서버를 재시작)
4. 브라우저에서 Ctrl+F5(모바일은 페이지 새로고침) 실행.
5. 공방에서 무료/구매 외형을 장착하고 캐릭터 얼굴·이름표 확인.

[검증]
- npm run build 성공 (Node 22.x)
- 독립 실행 가능한 Node 테스트 245개 중 239 통과, 6 스킵, 실패 0
- WebSocket 네트워크 테스트 파일 2개는 이 실행 환경에 ws 패키지가 없어
  구동 불가능했습니다 (실서버 다중 접속 테스트까지 검증됐다는 뜻이 아님).
- Chromium Canvas로 기존 게임 도트 아틀라스를 사용해 코스튬·날개·아우라·
  이름표를 중첩 렌더링하고, 각 부위 신규 120종이 서로 다른 이미지임을 확인.
- Chromium CSS 레이아웃: 1440x900, 1280x720, 1024x768, 840x630,
  768x600, 701x720, 390x844, 844x390에서 채팅·스킬바 교집합 0px 확인.
- 기존 저장 기록 삭제나 이미 구매한 코스튬 초기화 없음.

[주의]
- 이 ZIP은 직전 공방/시련 업데이트가 이미 적용된 코드 위에 덮어씌워야 합니다.
- UI/Canvas 및 서버 단위 테스트 위주이며, 실서버 동시 이용자의 장기 플레이는 별도 검증이 필요합니다.
