[수정 내용]
- 기업/M&A 기업 브라우저 레이아웃 전면 정리
  * 큰 빈 공간/카드 절단/2열로 깨지는 현상 제거
  * 회사명, 지분, 기업가치, 주가를 한 줄형 리스트로 정리
  * 화면이 좁으면 자동 1열 배치
- 기업 검색
  * 검색 후 첫 결과를 자동 선택/분석
  * 검색 결과 회사 버튼을 누르면 바로 선택 상태로 반영
- 뉴스/IR 회사 검색
  * 검색 결과가 1개면 즉시 기사 대상으로 선택
  * 결과 버튼 클릭 즉시 현재 대상 회사로 변경
- 재직 핵심인재 간편 목록
  * 이름/등급/부서/역량/잠재력/월급/자동운영 기여를 한 번에 표시
  * 각 직원 옆에서 바로 해고 가능
  * 실제 퇴직비용/사기하락/인원감소가 서버 데이터에 반영
- 경영권 공격 조건 변경
  * 아무 이유 없는 랜덤 공격 차단
  * 아래 중 하나일 때만 경영권 공격 가능
    1) 내가 먼저 상대 지분을 0.25% 이상 매입
    2) 내가 상대 회사에 비판·검증 기사 발행
    3) 기업가치 순위가 바로 위/아래인 직접 경쟁사
  * 공격 화면에 공격 배경 표시
  * 패치 적용 전 만들어진 이유 없는 ACTIVE 인수전 자동 종료
