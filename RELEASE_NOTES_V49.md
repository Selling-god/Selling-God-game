# RIFT DECK v4.9 — Retro Pixel Art Pass

This release is a visual-system patch. Game rules remain unchanged.

- 205 base monsters and all 615 form images regenerated with distinct anatomy/motifs and native pixel treatment.
- 30 biome scene backgrounds rebuilt as nearest-neighbor pixel environments.
- Global menu, party, collection, route, reward, modal, and battle chrome unified into a handheld-era pixel UI.
- Battle layout now gives player and enemy independent columns; double battles split only within their own side.
- Sprite and HUD maximum sizes are constrained at desktop/tablet/mobile breakpoints to prevent clipping and overlap.
- Asset generation scripts are included so future monsters can follow the same art system.
