RIFT DECK : ABYSS EXPEDITION v2.2.0 - 로그인/전투연출 업데이트

[기존 v2.1에서 업데이트하는 가장 간단한 순서]
1. PATCH ZIP의 파일을 GitHub 저장소 루트에 그대로 덮어쓰기
2. Supabase -> SQL Editor에서
   supabase/RUN_THIS_IN_SUPABASE_RIFT_V22.sql 을 1회 실행
3. Render -> 현재 사용 중인 RIFT DECK Web Service -> Environment에 2개 추가
   SUPABASE_URL = 기존 Supabase Project URL
   SUPABASE_SECRET_KEY = sb_secret_... (권장)
   * 예전 service_role 키만 있으면 SUPABASE_SECRET_KEY 대신
     SUPABASE_SERVICE_ROLE_KEY 이름으로 넣어도 됨
4. Save Changes -> 자동 재배포
5. 게임주소/healthz 에서 version=2.2.0 / auth=supabase 확인
6. 게임 접속 -> 계정 생성 -> 로그인/저장 테스트

[기존 Web Service 그대로 사용]
Build Command : npm ci && npm run build
Start Command : npm start
Node Version   : 22
Health Check   : /healthz

- 진행 중인 방/전투도 Supabase snapshot으로 저장해 Render 재시작 뒤 복구
