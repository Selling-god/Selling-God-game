RIFT DECK : ABYSS EXPEDITION v2.6.0

1. Render는 기존 RIFT DECK Web Service를 그대로 사용합니다.
2. Build Command: npm ci && npm run build
3. Start Command: npm start
4. Supabase 설정은 v2.5와 동일하며 새 SQL 실행은 필요 없습니다.
5. PATCH 사용 시 PATCH_APPLY_V26.txt의 파일을 GitHub 루트에 덮어쓰세요.
6. 배포 후 /healthz에서 version=2.6.0을 확인하세요.

v2.6 주요 변경
- 전투 화면 한 화면 재구성
- 적 흰 배경 제거
- 카드/스펠/유닛/적 움직임 강화
- 장면 전환 픽셀 커튼
- RIFT BREAK
- 던전 경로 화면 단순화
- 게스트 -> 클라우드 로그인 기록 선택
- 렌더/파티클 최적화
