SELLING GOD V7.0 REAL CEO - OPEN-ENDED MANAGEMENT PATCH

기준 버전
- V6.7.0 CEO Experience + CEO Lounge 이후 버전

적용 방법
1. ZIP을 압축 해제합니다.
2. 기존 프로젝트에 아래 파일을 같은 경로로 덮어씁니다.
   - public/app.js
   - public/styles.css
   - app.js
   - styles.css
3. Render에서는 기존 설정 그대로 npm run build가 실행되면 out 폴더까지 자동 생성됩니다.
4. 배포 후 Ctrl+F5로 강력 새로고침합니다.

이번 버전 핵심

[1] 엔딩 없는 중기 경영 목표
- 게임 종료 조건을 만들지 않았습니다.
- CEO 홈에 '중기 경영 목표'를 추가했습니다.
- 목표는 회사 성장에 따라 자동으로 다음 단계가 제시됩니다.
- 현금 버팀 기간
- 영업이익률
- 기업가치
- 기업가치 순위
- 조직/제품 건전성
- 과도한 코인/XP/보상 UI 없이 실제 이사회 목표처럼 표현했습니다.

[2] 상단 메뉴 가로 이동 UX 수정
- 좌/우 이동 화살표 추가
- 더 볼 메뉴가 있는 방향에 시각적 그라데이션 표시
- 마우스/터치 드래그로 메뉴를 밀다가 손을 떼도 탭이 잘못 눌리지 않도록 수정
- 탭을 클릭한 뒤에도 기존 가로 스크롤 위치를 기억
- 화면 재렌더링 후에도 메뉴가 맨 앞으로 돌아가지 않도록 수정
- 모바일 하단 메뉴에도 같은 방식 적용

[3] 기존 기능 유지
- V6.7 CEO 라운지 유지
- 기존 BOT, M&A, 기업분석, 직원, 세금, 공급망, 재무 시스템 유지
- Supabase 구조 변경 없음
- 추가 SQL 실행 필요 없음

검증
- node --check 통과
- npm run build 통과
- root/public/out/dist/build/site 배포 루트 생성 확인
