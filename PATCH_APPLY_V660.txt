Selling God v6.6.0 CLEAN PATCH

변경 내용
1. BOT 회사들이 서로 지분전, 공개매수, 인수, 방어, 인재 스카우트, 언론전, 전략적 제휴를 벌이는 공용 기업전쟁 레이어 추가
2. 회사 ID + 서버 경영주기 기반 결정론적 결과로 모든 접속자가 같은 BOT 기업전쟁 결과를 봄
3. BOT 기업전쟁 승패가 해당 BOT 회사 기업가치/주가에 소폭 반영됨
4. 경영 홈/투자·M&A 화면에 '기업전쟁 LIVE' 피드 추가
5. 기업전쟁 피드에서 대상 회사 분석으로 바로 들어가 플레이어가 전투에 참여 가능
6. 경영권 위험 0%일 때 '현재 공격 없음 · 정상'으로 명확하게 표시
7. 플레이어 회사가 기업세계의 중심이 아니라 BOT 회사들과 같은 시장의 한 참가자라는 UI 문구로 변경

적용 방법
- ZIP의 app.js, styles.css를 프로젝트 루트의 같은 파일에 덮어쓰기
- ZIP의 public/app.js, public/styles.css를 public 폴더의 같은 파일에 덮어쓰기
- 나머지 파일은 건드릴 필요 없음

별도 Supabase SQL 실행은 필요하지 않습니다.
