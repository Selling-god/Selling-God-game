RIFT DECK V49 - RETRO PIXEL ART PATCH

[적용 방법]
1. 기존 프로젝트를 백업합니다.
2. 이 ZIP 안의 파일/폴더를 프로젝트 최상위에 그대로 덮어씁니다.
3. Render/GitHub에 다시 배포합니다.
4. 브라우저에서 강력 새로고침(Ctrl+F5)을 한 번 실행합니다.

[핵심 변경]
- 205종 기본 몬스터 + 진화/공명/균열 폼 전체를 오리지널 레트로 도트 스타일로 재생성
- 이름/계통별 서로 다른 몸체와 장식 규칙 유지 (단순 색상 복제 금지)
- 30개 바이옴/전투 배경을 픽셀 배경으로 재제작
- 홈/편성/수집/루트/보상/모달/버튼/상태창을 동일한 레트로 UI 규칙으로 통일
- 전투 아군/적군을 독립된 2열 레이아웃으로 분리해 서로 겹치지 않도록 수정
- 더블 전투도 각 진영 내부에서만 2분할하여 상대 진영 침범 방지
- PC/태블릿/모바일별 몬스터 최대 크기와 상태창 크기 제한
- 스프라이트 비율 왜곡 제거: 128x112 원본을 128x128 캔버스에 보존 후 NEAREST 확대
- 픽셀 외곽선/하이라이트/그림자 디더링 추가

[수정하지 않은 것]
- 전투 규칙/수치
- 세이브 구조
- Supabase 계정/방 로직
- 카드/아이템 데이터
- 포획/진화 조건
