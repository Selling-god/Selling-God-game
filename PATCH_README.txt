[패치 핵심]
- 매 층 2갈래 길 선택 중심 -> 몬스터 연속 웨이브 중심으로 변경
- 1~10웨이브를 하나의 바이옴 러닝 구간으로 구성
- 일반 웨이브: WILD ENCOUNTER
- 5웨이브: RIFT WARDEN / 강화된 2체 전투
- 10웨이브: BIOME BOSS
- 첫 시작에서 STARTER CORE(원정 서약) 선택 UI가 실제 진행 화면에 표시
- 다음 웨이브는 짧은 조우 게이트 후 자동 진입하여 흐름을 끊지 않음
- 전투/보상 화면에 1~10 웨이브 트래커 추가
- 5웨이브 워든 승리 후 야영 행동 + 유물 선택
- 4/9웨이브 승리 후 FIELD SHOP 등장 (다음 강적/보스 준비)
- 모든 전투 보상에서 FIELD SUPPORT 사용 가능
  * 응급 회복: CORE 15%, 생존 몬스터 22% 회복
  * 부활 캡슐: 쓰러진 몬스터 1체 HP 40%로 부활
  * 아르카나 충전: 다음 전투 시작 에너지 +1, 시작 패 +1 (최대 2충전)
- 10웨이브 보스 후 다음 바이옴 이동 시 CORE/몬스터 완전 회복
- JOURNEY의 야생/보스 몬스터 봉인은 유지, 워든은 봉인 대상에서 제외
- 기존 스펠 3택 보상, 재굴림, 덱 분해/정제, 스킬 디스크, 진화/융합/공명/RIFT, 멀티룸/Supabase 기능 유지

[설계 의도]
PokeRogue 소스를 복사한 패치가 아닙니다.
공개된 PokeRogue의 '연속 전투 -> 전투 후 선택 보상 -> 5/10웨이브 강적 -> 10웨이브 바이옴 전환' 같은 런 템포를 분석하여,
현재 RIFT DECK 코드와 몬스터/스펠 시스템에 맞게 독립적으로 구현했습니다.
이 게임만의 핵심 차별점은 몬스터 기술이 주 행동이고, 스펠 카드는 턴당 제한된 전술 행동으로 몬스터의 GENE/RES/RIFT/COMMAND LINK 성장과 직접 연결된다는 점입니다.
