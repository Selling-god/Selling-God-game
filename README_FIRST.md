# 판매의 신 / KX CORPORATE V6.3

이번 버전은 **핵심인재 시장 + 경쟁사 헤드헌팅 + 활동 연계 뉴스 + 경쟁사 비판보도 + 주식 즐겨찾기**를 추가합니다.

## 반드시 먼저
현재 V6.2가 정상 적용된 상태에서 Supabase SQL Editor에 `RUN_THIS_IN_SUPABASE_V6.3.sql` 전체를 1회 실행하세요.

기존 유저, 회사, 주식, 은행, M&A, 제품, 재무 데이터는 삭제하지 않습니다.

## 핵심 변경

### 1. 일일 핵심인재 채용시장
- 게임 일자마다 후보 10명 자동 생성
- 하루 최대 5명 채용 가능
- 등급: 신입 / 경력직 / 수재 / 천재
- 개인별 부서, 전문분야, 종합역량, 혁신, 영업, 운영, 리더십, 월급, 사인보너스
- 좋은 핵심인재가 많을수록 회사의 기술, 제품, 영업, 운영, 준법, 조직지표가 장기적으로 개선
- 핵심인재의 높은 계약월급은 실제 비용으로 반영

### 2. 경쟁사 인재 헤드헌팅
- BOT 회사와 다른 실제 유저 회사의 핵심인재에게 이직 제안 가능
- 제시 월급과 사인보너스를 직접 입력
- 현재 회사의 직원사기/브랜드, 상대 회사의 근무환경, 인재 등급/충성도에 따라 수락확률 변화
- 실패해도 헤드헌터 착수금 발생
- 성공하면 상대 회사는 해당 인재와 1명의 인원을 실제로 잃음

### 3. 언론 기사 방향
- 긍정 홍보 / 사실 중심 / 비판·검증
- 다른 유저 회사도 기사 대상으로 선택 가능
- 실제 유저 회사는 기사 선택 화면에서 별도 강조
- 비판·검증 보도는 역풍과 법무비용 위험 존재

### 4. 활동 연계 기사
- 최근 프로젝트, 제품, 인사, M&A, 해외진출, 이사회 사건이 있으면 그 활동을 기사 주제로 우선 사용
- 같은 활동이어도 여러 헤드라인 템플릿 중 랜덤 편집
- 최근 활동이 없어도 실적, 현금, 기술, 품질, 인재, 공급망, 해외시장, 내부통제, 경쟁 등 다양한 기사 생성
- 자연 발생 시장기사도 추가

### 5. BOT 경쟁사 견제 보도
- 플레이어 회사가 매출, 투자심리, 시장모멘텀, 해외점유율 등에서 눈에 띄기 시작하면 경쟁사 BOT가 견제성 비판 보도를 낼 수 있음
- 경쟁사의 실제 보도비용도 차감
- 과도한 견제는 BOT 쪽에 역풍이 날 수도 있음

### 6. 주식 즐겨찾기
- 종목 옆 ☆ 버튼으로 즐겨찾기
- 즐겨찾기 종목은 순위와 무관하게 목록 최상단에 고정
- 차트 상단에서도 즐겨찾기 가능
- 브라우저/로그인 사용자별로 저장
- 국가 필터도 전체 / 국내 / 미국 / 중국 / 유럽 / 일본으로 직접 작동

## 설치
1. `app.js`, `styles.css`, `public/app.js`, `public/styles.css` 교체
2. Supabase SQL Editor에서 `RUN_THIS_IN_SUPABASE_V6.3.sql` 전체 실행
3. 배포 후 강력 새로고침
