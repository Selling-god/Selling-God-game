# 판매의 신 / KX CORPORATE V6.4

V6.4는 화면에 안내문을 더하는 패치가 아니라, 직원·언론·경영권 방어를 실제 경영 로직에 더 강하게 연결하는 개편입니다.

## 반드시 실행
기존 V6.3까지 적용된 Supabase에서 `RUN_THIS_IN_SUPABASE_V6.4.sql` 전체를 SQL Editor로 한 번 실행합니다.

## 주요 변경
- 상단에 `직원` 독립 탭 추가
- 매 DAY 후보 10명, 최대 5명 채용
- 직원 잠재력, 무제한 Career Level, 자연성장, 종합/전문 연수
- 잠재력이 높아도 연수 성공은 보장되지 않음
- 직원 능력치가 회사 기술·제품품질·수요·생산·공급망·프로젝트 성공률에 직접 반영
- BOT 및 다른 유저 회사가 핵심인재를 스카우트 가능
- 실제 유저 회사 인재를 빼오려 하면 원 소속 회사에 이직 제안이 도착하며 맞제안 가능
- 뉴스에서 회사명·티커·유저명 검색
- 실제 유저 회사는 검색결과에서 금색, 내 경영권 위협 회사는 붉은색 표시
- 경영권 위협 회사를 바로 비판기사 대상으로 보내거나 회사분석/M&A 화면으로 이동 가능
- 기사 발행 RPC를 V6.4로 분리하여 홍보/사실/비판 보도 실행 안정화
- 경영권 방어 비용을 실제 시가총액·주식수·투입예산에 비례하도록 수정
- 역인수로 산 공격회사 지분을 실제 `my_holdings` 기준으로 표시
- CEO ASSISTANT/우선순위 안내 등 비게임성 안내판 제거
- 사업 운영을 제품/프로젝트/공급망/재무/법인투자/해외시장 탭으로 재배치해 긴 스크롤 감소

## DB 데이터
기존 유저, 회사, 돈, 제품, 주식, 지분, 인수전, 직원 데이터는 삭제하지 않습니다.
