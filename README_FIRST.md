KX CORPORATE V6.4.1

이 패치는 V6.4.0의 경영 화면에서 발생한 치명적인 프런트 렌더 오류와 경영권 방어 화면 공간 낭비를 수정합니다.

핵심 원인:
- 비대시보드 화면에서 호출하는 `renderCompanyCompactContext()` 함수가 누락되어 있었습니다.
- 그래서 사업/직원/M&A/뉴스 등으로 이동할 때 `ReferenceError`가 발생하고 이후 버튼 처리와 화면 렌더링이 중단되었습니다.
- 경영권 방어 KPI 컨테이너에는 grid 레이아웃 선언이 빠져 있어 숫자들이 세로로 길게 늘어졌습니다.

SQL 재실행은 필요하지 않습니다.
