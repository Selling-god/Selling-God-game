RIFT DECK v4.2.0 PATCH APPLY
============================

1. 기존 프로젝트를 백업합니다.
2. 이 패치 ZIP을 기존 프로젝트 루트에 덮어씁니다.
3. 아래 명령으로 검증합니다.

   npm test

4. 배포 환경에서는 기존과 동일하게 실행합니다.

   npm ci && npm run build
   npm start
